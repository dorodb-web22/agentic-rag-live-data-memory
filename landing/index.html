FAQ

Questions, answered

What can I connect?

Today it works with GitHub and SQLite through the Model Context Protocol. Any MCP server can be added as another source.

How is this different from a normal AI chatbot?

A chatbot answers from what it was trained on. This agent reads your live tools at the moment you ask, then shows which source each claim came from.

Does it remember past conversations?

Yes. Each thread is saved, so a follow-up picks up exactly where you left off without repeating context.

How do you stop wrong answers?

Answers are written only from retrieved data, cited inline, and scored against that data. If the evidence is thin, the agent searches again before it answers.

How does sign-in work?

You sign in with your Google account. We receive your name, email and profile photo, and we don’t see your Google password.
